A premium trekking and adventure trip management plugin for WordPress.

== Description ==

Adventure Treks is a powerful, enterprise-grade WordPress plugin designed for adventure agencies, travel companies, and trekking organizations. It enables comprehensive itinerary scheduling, multi-city departure points, pricing rule hierarchies, and real-time frontend slot checking with dynamic AJAX widgets.

== Installation ==

1. Upload the `adventure-treks` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Use the Adventure Treks menu to configure custom posts and custom departure settings.
